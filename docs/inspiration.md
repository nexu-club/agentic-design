# Inspiration & Prior Art

A living list of products, papers, and ideas that shape how we think about Open Design.

Got a link we should add? Open a PR.

## 🎨 Design tools

- **Figma** — the baseline. Multiplayer canvas, component systems, plugin API.
- **tldraw** — minimal, hackable canvas. `makereal` experiments with LLM→UI.
- **Penpot** — open-source design tool, worth studying the FOSS-design playbook.
- **Framer** — design-to-code continuum, good for what "production-ready design" feels like.

## 🤖 Agent-native / chat-as-workspace

- **Claude Code** — what "agent-native" workflow feels like in code. We want that for design.
- **Cursor** — design-time AI that understands project context.
- **v0.dev** — generate UIs from prompts; a glimpse of text-to-design.
- **Lovable** — prompt-to-production for web apps; the "one-click deploy" inspiration.
- **Bolt.new** — in-browser full-stack + AI.

## 💬 Chat-native collab

- **Slack** — the default for "a team in a room." We respect it, we're not replacing it, we're next to it.
- **Discord** — what a vibrant community chat feels like.
- **Lark / 飞书** — best-in-class integrated productivity suite; a proof that IM can be the OS of work.

## 🧪 Open-core playbooks

- **OpenCode** — open source + managed service model we study closely.
- **Supabase** — open-source + hosted, developer love, clean commercial edges.
- **PostHog** — open-core analytics; product-led growth done right.
- **Terminus Studio** — inspiration for how agent-native tooling goes open and monetized.

## 📄 Papers / essays

- **"The Bitter Lesson"** (Sutton) — general methods that scale with compute beat hand-tuned ones. We lean into agents, not heuristics.
- **"Teach LLMs to Phish"** — ignore, this is just here to show the list is curated.
- **Anthropic's "Building Effective Agents"** — practical patterns for multi-agent systems.
- **Karpathy's "LLM Wiki" tweets** — long-context workspaces as living knowledge bases.

## 🧭 Principles we disagree with

For contrast, here's what we're **not** doing:

- ❌ "AI-first" as just "paste GPT into the sidebar" — that's AI-decorated, not AI-native
- ❌ Infinite-canvas purity — canvases without chat are dead canvases; our users want a team, not a whiteboard
- ❌ Open source as a marketing sticker — we're open because the agent runtime needs to be inspectable; not because it's trendy
- ❌ Replacing designers — we're **arming** them with agent teams, not removing them
